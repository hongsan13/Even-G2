# G2 / Even Hub 実機リリースチェック

未実施のチェックを完了扱いにしない。日付・Even App版・G2 firmware・OS・データの出典/版を記録する。

1. `npm ci`、`npm run check`を実行し、`releases/transit-hud-0.1.0.ehpk`を公式Hubへアップロードする。package_idと提出条件を確認する。
2. Even App >= 2.2.10の通常のHub画面からインストール・起動する。Prototype/QR/Viteサーバーを使わず、PCを停止して検証する。
3. 未設定の画面を確認。スマホで地域GTFS ZIPを選択できるか確認する。Worker/IndexedDBが利用できることをデバッグ情報で確認する。使えない場合、SDK分割fallbackと4MB制限を確認する。失敗表示を記録する。
4. 実データの出典と使用条件を確認する。都営大江戸線の実データを確保できない場合は交通局の最新時刻表から個人利用分を手入力する。サンプルを実時刻表として使わない。
5. 練馬春日町→新宿と帰りを登録。徒歩7分、余裕2分で3候補・到着時刻・MISSED時の次候補選択を確認。番線がなければ表示されないことを確認。
6. 日本語の欠け/文字幅/改行、6containersの位置、3本が読めること、注意文が収まることを確認する。長い駅名・行先で切れないか確認する。
7. Tap、Scroll上下、長押しContextual Menu、お気に入り切替、Double Tap終了を確認。長押しが列車選択として誤作動しないことを確認する。
8. アプリを閉じて再起動。設定と時刻表の保持を確認。WebView更新/Hubプラグイン更新でデータが保持されるか、アプリの仕様を確認する。
9. PCを停止し、スマホを機内モードにしてオフライン次発・お気に入り切替を確認する。BluetoothはG2表示のため有効にする。Hubからの冷起動がオフラインでも可能か記録する。
10. 23:59→翌日00:05、平日→土曜、祝日例外、終電後→翌日始発、使用曜日外、有効期限切れを確認する。
11. 直通と1回乗換。必要乗換時間、禁止乗換、手動乗車モードの行動遷移を確認。実際の乗車検知ではないことを確認する。
12. 対応するRealtimeファイルを取り込み、遅延・運休・SKIPPEDを確認する。2分後に予定時刻へ戻ること、古いフィード/デコード障害でアプリが停止しないことを確認する。
13. 公開配信を有効にした場合だけ、実WebViewでCORS・network whitelist・HTTPS・ETag/Last-Modified・再取得頻度を確認する。認証鍵を配布しない。
14. スマホのバックグラウンド/フォアグラウンド、Bluetooth切断/再接続で画面更新が復旧するか確認する。バッテリー・更新頻度を実測する。
15. キャッシュ削除、複数お気に入り削除、データ更新、期限切れを確認。設定・個人情報をログ/外部通信へ出していないことを確認する。

本ファイルは手順書であり、上記が合格したという証拠ではない。実測結果がそろってから公開品質と判定する。
