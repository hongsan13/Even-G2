# Privacy Policy / プライバシーポリシー

Transit HUD v0.3.0 / 2026-10-05

Transit HUDは、Evenアプリ内で利用する時刻表・徒歩時間設定による乗車案内プラグインです。

- お気に入り移動、徒歩・余裕時間、手入力時刻表、取り込んだGTFS・列車時刻表JSONは端末内の公式SDKストレージまたはWebViewのIndexedDBに保存します。
- 開発用ブラウザでは同じブラウザのlocalStorage/IndexedDBを使います。ブラウザの設定はEvenアプリへ自動移行しません。
- 位置情報、カメラ、写真、マイク、連絡先、ODPTの登録プロフィールは取得しません。任意に入力された認証トークンはメモリに保持します。
- 個人情報、ルート設定、時刻表ファイルを開発者のサーバーへ送信しません。解析・広告SDKは含みません。
- 標準版は、初期設定で起動時と利用中1日ごとに選択済み公式GTFS・JSONの更新を確認します。「自動更新」を停止できます。取得先はapi-public.odpt.org、api.odpt.org、api-challenge.odpt.org、dataodpt.blob.core.windows.netで、配信元はIPアドレス等の通常のアクセス情報を受け取ります。設定・現在位置・手動補正は送信しません。配信元の利用条件とプライバシーポリシーも確認してください。
- ODPTトークンは確認済み公式配信へ取得時に送信します。ログ・時刻表キャッシュ・SDK設定・配布物には保存しません。「トークンを解除」または再起動で解除します。配信元には選択した事業者・路線の要求が送られます。
- 限定ライセンスの期限後は、該当時刻表を起動時・利用中に削除します。早期提供終了の場合はユーザーが該当データを削除してください。
- G2表示に必要な案内内容はEvenアプリの公式Bridgeへ送ります。Evenアプリ・Even Hub自体のデータ取扱いはEven Realitiesの規約に従います。
- 「時刻表・キャッシュ削除」で時刻表、お気に入り、配信URLを削除できます。表示設定（更新頻度等）は残ります。アプリのデータ削除やアンインストール時の挙動はEvenアプリの仕様に依存します。
- 乗車モードとRealtime情報はメモリ上で保持し、通常は再起動で消えます。

初期データとして東京都交通局・公共交通オープンデータ協議会の公式GTFSを同梱します。手動の時刻補正と乗換徒歩時間はユーザーが確認して入力します。配布される架空サンプルは検証専用です。最新の運休・実際の列車位置・ホーム動線を保証しません。駅や事業者の案内を優先してください。

問い合わせは[このプロジェクトのGitHub Issues](https://github.com/hongsan13/Even-G2/issues)へ。ルート名や個人の移動情報を公開投稿しないでください。
