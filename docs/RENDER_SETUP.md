# Renderで始める：操作は最初の配置だけ

こちらでサーバー設定を用意しました。URLを考えたり、ドメインを購入したりする必要はありません。**現在はユーザーがtransit-hud.onrender.comへ配置済みです。既存サービスは再作成しないでください。** Renderのアカウント操作・利用規約への同意はご本人が行ってください。このチャットからRenderのログイン画面を操作する接続はありません。

## 最初にすること

1. **[Renderで配置を始める](https://render.com/deploy?repo=https://github.com/hongsan13/Even-G2)** を開きます。
2. Renderへ登録/ログインします。GitHub連携を求められた場合は、このリポジトリ `Even-G2` を接続します。
3. `transit-hud` のサービスが表示されたら、プランが **Free** になっていることを確認し、画面の配置開始ボタン（Deploy / Applyなど）を押します。その他の項目は基本的に変更不要です。
4. ビルドが終わり **Live** になったら、表示される `https://…onrender.com` のURLをコピーしてチャットへ送ってください。トークンやパスワードは送らないでください。

設定は[render.yaml](../render.yaml)から読み込まれます。Node.jsの版、ビルド/起動コマンド、都営の初期データ、健康確認、管理用トークンの自動生成まで指定済みです。最初の配置時にODPTトークンの入力は不要です。サービス名が重複しているなどのエラーが出た場合は、そのエラー文だけ教えてください。

## URLが発行された後

URLを受け取ったら、公開サーバーの動作をこちらで確認し、そのURLを組み込んだHub用ファイルを作ります。v0.4.1はHub向け公開案内APIと管理APIのCORSを分離しています。最初にManual Deploy → Deploy latest commitでサーバー更新を反映し、Hubへv0.4.1をアップロードしてください。実機通信も確認してから一般公開を判断します。**サービスがLiveになっただけで、既存のHubファイルが自動的につながるわけではありません。**

管理ページは同じURLの末尾に `/admin` を付けた場所です。管理用トークンはRenderが自動生成し、サービスの環境設定に保存します。チャットへ貼らず、ご自身の管理ページで使います。

JRや東京メトロ等を追加する際は、一般利用者へ提供できる範囲を確認し、Renderのシークレット設定へODPTトークンを入れます。その作業は最初の都営での接続確認後に進めます。トークンを一般利用者に配りません。

## 無料設定について

この設定は試用向けです。Renderの公式案内では、無料Webサービスは15分間アクセスがないと休止し、復帰に約1分かかります。休止後は管理ページなどを先に開いて待ち、Hubの更新を再試行してください。無料枠の時間・帯域などにも制限があります。日常利用向けに常時稼働させる場合は、実際の料金を確認してからプランを判断します。有料プランへの自動変更設定は入れていません。

GitHubへの更新による自動再配置も停止しています。サーバーの更新が必要になったときはRenderのManual Deploy等で行います。

## 確認したことと残ること

- Render公式のBlueprint JSON Schemaで `render.yaml` の形式を検証済み。
- Node.jsサーバーのビルド、Renderが発行するURLに相当する環境設定での起動・都営149駅/6路線取得・CORSをローカルで検証。
- Renderアカウント内での配置、発行URLへの実通信、料金表示、G2実機接続はまだ未確認。
