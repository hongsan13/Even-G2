# 配布物

現在のオンライン版: [transit-hud-0.4.8.ehpk](transit-hud-0.4.8.ehpk)

接続先は **https://transit-hud.onrender.com**。利用者はトークン入力や時刻表取込なしで、駅とルートを選びます。公開サーバーで都営＋東京メトロ334駅・15路線を確認済み。その他の事業者の実取得は未検証です。

**最初にRender側をManual Deploy → Deploy latest commitで更新し、Liveを確認してください。** 以前のサーバーはHubからのCORS要求を拒否します。v0.4.1のサーバーは公開案内APIだけ資格情報なしのブラウザ接続を許可し、管理APIのorigin制限と認証は維持します。

その後、同じEven Hubプロジェクトへこの.ehpkをアップロードしてください。G2実機での通信・操作は未検証です。無料Renderは休止後の復帰に約1分かかります。初回取得は最大90秒待ち、失敗後は自動再試行します。Hubの画面は案内とお気に入りに集約し、手動取込・認証・更新設定は表示しません。新規ルートは直通と最大2回の乗換を自動比較します。

SHA-256: `92b4cbf04842604ff6d027b49c1029bbc662d0484e2ddaeb00f613c0abe0cdf6`

再生成: `npm ci` → `npm run pack:online`（Unix系シェル）。標準の`npm run pack`は接続先未設定なので、同名の配布物を再生成するときはコマンドに注意してください。

前版: [接続先未設定のv0.4.0](transit-hud-0.4.0.ehpk)。

v0.4.4ではオンライン版の先頭に出発駅・到着駅・乗換駅（任意）の検索フォームを配置。お気に入りの選択・編集・削除は折りたたみ内です。検索すると自動名でお気に入りに保存します。路線・方面・最大乗換の入力は不要で、直通と最大2回乗換を比較します。

v0.4.5ではルート検索も初期状態で折りたたみ、保存後も閉じます。「＋乗換駅を追加」で経由・乗換駅を順序付きで最大3枠まで追加・削除できます。駅指定の枠数と実際の乗換回数は別で、乗換回数は最大2回です。

v0.4.6では出典・利用条件・操作ガイドを画面最下部の折りたたみへ移動。ODPT/公式列車時刻表JSONのサーバー設定手順は[こちら](../docs/ODPT_ACTIVATION.md)。認証付き事業者の実接続は未検証で、公開配信を追加した版ではありません。

v0.4.7はメトロGTFSに含まれる1駅だけの列車レコードで全体の取込が止まる問題を修正。レコード自体は保持し、その便から乗車経路を作りません。添付実データの185駅/9路線/9,706レコード、都営との統合334駅/15路線、サーバーWorker検索を確認しました。メトロ原データは同梱していません。オンライン版のメトロ取込にはRenderのManual Deployが必要で、この修正だけなら既存Hub v0.4.6も利用可能です。

v0.4.8では横浜市営地下鉄の通常ODPT GTFS（公式20251226版）を追加し、Renderの `TRANSIT_FEEDS=kanto` で関東10配布元を選択できます。[各社の対応状況と設定](../docs/KANTO_COVERAGE.md)。京王・東武・相鉄・JRにはチャレンジ専用鍵が必要。小田急・西武の乗換検索は未対応です。オンライン版はサーバー反映とHubの再起動で新駅を取得できるため、今回の追加だけなら.ehpk入替は必須ではありません。
