# Even-G2 · Transit HUD

Even Realities G2向けのスタンドアロン乗車案内プラグイン。スマホのEvenアプリ内で時刻表を処理し、徒歩と余裕時間を含めて「今出れば乗れる電車」をG2へ表示します。通常利用に開発PC・Node.jsサーバー・個人バックエンドは不要です。

**v0.3.0：駅名検索・最大2回乗換・公式JSON取込・認証付きGTFS取得に対応した実機確認前の版です。認証配信は未接続検証です。全国全路線を収録したものではありません。**

v0.3.0では最大2回の乗換（3本の列車）を検索できます。保存ルートの「編集」→「最大乗換」→「2回」を選んで保存してください。必要なら最初と2つ目の乗換駅を駅名で指定できます。既存ルートの上限は自動で変更しません。

## v0.3.0の使い方

1. 同じEven Hubプロジェクトに `releases/transit-hud-0.3.0.ehpk` をアップロードして更新。
2. 初回は都営全線の公式GTFSが自動で準備されます。出発駅・到着駅の名前を入力し、候補から選択。同名駅は路線で区別できます。
3. 必要なら乗換駅・経由駅、徒歩・余裕を指定して登録。表示名は省略可能です。候補ごとの乗換駅と時刻も確認できます。
4. 「公式データを追加・更新」で地域を追加。全国の互換GTFS ZIPも端末から追加できます。地域ごとのデータを削除して容量を調整できます。
5. 都営は起動時と利用中1日ごとに最新版を確認。手動更新・自動更新停止も可能。通信失敗時は保存済みデータを使用します。日付固定URLはカタログで最新版を確認してください。
6. 保存ルートはいつでも編集できます。「時刻表を手動で補正する」は端末内の全運行日への補正で、公式時刻とは区別して表示します。

公開配信一覧は都営鉄道全線と高知のとさでん交通・路面電車。認証付きGTFS一覧にJR東日本（関東の一部路線）・京王・相鉄・東武・東京メトロ・つくばエクスプレス・りんかい線・多摩都市モノレールを追加しました。入手先の公式カタログは確認済みですが、認証付き実データの取得・経路検索は未検証です。認証データは同梱しません。全国一括取込・全路線対応・運賃・3回以上の乗換には未対応です。最大8配布元/40,000便/10,000駅で、SDK圧縮保存は4MBまで。全国対応は必要な地域を保存する構成で進めています。

配布元間の乗換はGTFSだけで確定できないため、実際に乗換できる駅と徒歩時間をユーザーが確認して連絡できます。同名駅の自動接続は行いません。

## 認証配信とGTFS以外のJSON（v0.3.0）

1. [ODPT登録手順](docs/NON_GTFS_RESEARCH.md#odptの登録手順)に従い登録。通常トークンとチャレンジ専用トークンは別です。
2. 「ODPT認証設定・登録方法」で必要なトークンを入力し「今回の利用中だけトークンを設定」。チャットやGitHubへトークンを貼らないでください。
3. GTFSを使う場合は「追加する地域・事業者」から選び、利用条件を確認して取得。保存済みデータを更新するボタンで再取得できます。
4. GTFS以外は「公式の列車時刻表JSONをオンライン取得」からJR東日本・京王・東武・相鉄を選び、路線一覧を取得。路線と、確認済みの有効期間・祝日を指定して取り込みます。同じ路線の再取込で期間も更新できます。
5. 正式に取得したRailway・Station・TrainTimetableのJSON配列ファイル3点も端末から取り込めます。同じ保存先を選べば更新になり、使う駅を名前で検索・選択してルート登録できます。

JSONの祝日・期間は自動推測しません。初回に確認した期間を使って更新するため、ダイヤ改正後は期間・祝日も確認して再取込してください。API応答が1000件以上なら欠落のおそれがあるため保存せず、全件を確認したファイル取込を案内します。未知の運行日、分割された直通列車の結合、駅別発車表からの到着時刻推定は未対応です。取込失敗は既存データを保持します。

チャレンジ2026の限定データは2027-03-12まで（早期終了の可能性あり）。期限後は起動時・利用中に端末キャッシュから削除し、該当便を案内しません。早期提供終了時はユーザーが該当データを削除してください。通常のダイヤ有効期間の終了とは区別します。新幹線・関西・中京・九州の網羅データ取得は未確認です。[調査記録](docs/NON_GTFS_RESEARCH.md)。

認証付き取得の状態遷移は公式仕様に沿った架空の応答で検証しました。認証付きの実データ・CORS・Azure転送先・Even Hub実機通信は未検証です。登録と配信側の利用許諾が必要であり、対象全便を取得できるという保証ではありません。

## できること

- 次発3本、24時間表記、Asia/Tokyo、予定発車・到着、路線・行先・番線（データがある場合）。
- `現在時刻 + 徒歩時間 + 発車前余裕 <= 発車時刻`による乗車可否。SAFE/LEAVE_NOW/TIGHT/MISSEDを文字と記号で表示。
- 行き/帰りを含む8件のお気に入り、方面・経由・優先/除外路線・固定経路、曜日と時間帯による自動切替。当日の手動選択が優先。
- 直通と最大2回乗換、到着時刻、最低乗換時間、手動乗車モードの「次の行動」。
- 複数の地域GTFS ZIP/GTFS基本列を含むGTFS-JP、祝日例外、24時以降、ローカルキャッシュ。通信障害でも予定時刻で動作。
- スマホでの手入力時刻表。平日/土休日、行き/帰り、個別祝日、有効期間、所要時間。
- 公式GTFS-Realtime protobufによる遅延・運休。ファイル取込と、配信元設定済みビルド向けHTTPS更新アダプター。
- 公式SDKのContextual Menu、Tap/Scroll、差分描画。10〜60秒の更新頻度。

位置情報、3回以上の乗換、全国経路検索、頻度ベースのGTFS、臨時/変更列車などは未対応です。詳細は[PROGRESS.md](PROGRESS.md)と[調査結果](docs/RESEARCH.md)。

## 都営の実ZIPでの確認（v0.3.0）

ユーザー添付の `Toei-Train-GTFS.zip`（版20260921、有効終了20270312、149駅・6路線・5600便）で取込・次発・保存・オフライン操作を検証しました。未記載時刻は浅草線・新宿線の乗降不可駅540行で、大江戸線にはありませんでした。

練馬春日町→新宿は、出発駅438、到着駅428（新宿線の301と異なる）、路線4、方面1で登録します。方面の番号はこのフィードの値です。固定テスト時刻2026-10-05 13:43 JST、徒歩7分・余裕2分では、13:56発／14:02発／14:08発、最初の新宿到着14:18を確認しました。これは現在時刻の案内ではありません。

実ZIP回帰テストは、対象版のZIPを `TOEI_GTFS_ZIP=/path/Toei-Train-GTFS.zip` に指定して `npm run test:browser` を実行します。指定なしでは実ZIPの2件をskipします。同じ都営ZIPを初期データとして同梱します。他地域は追加して使用します。

## ユーザーの導入手順

1. 作成された`.ehpk`を開発者が[Even Hub](https://hub.evenrealities.com/)へアップロードし、ユーザーはEvenアプリの通常のHub画面からインストールします。Even App **2.2.10以上**とペアリング済みG2が必要です。公開にはHubの審査・提出条件に従ってください。
2. スマホのプラグイン設定画面で、都営の初期データから出発・到着駅と徒歩時間を登録します。他地域は公式一覧または利用条件を確認したGTFS ZIPから追加します。GTFSがない場合は「公式時刻表を見ながら手入力する」から行き/帰りの時刻・所要時間・祝日・有効期間を入力します。
3. G2で起動します。Tapで次の候補、Scrollで前後、長押しの公式メニューでルート切替、Double Tapで終了します。初期設定後に開発PCを動かす必要はありません。

実データの更新時は再取込または手入力を更新します。通常のデータ追加・更新はお気に入りを保持します。全置換・手入力の新規登録・サンプル切替は現在の時刻表とお気に入りを置き換えます。初回操作の簡略化には、再配布可能な実データまたは検証済みの公開配信元の確保が必要です。

オフライン検索は保存した時刻表を使います。最終取込からの経過時間を表示し、有効期限切れでは新規の乗車案内を止めます。祝日はGTFSの`calendar_dates`または手入力の祝日一覧に従い、勝手な推測をしません。日付を跨ぐ時刻はGTFSと同じ`24:05`表記で入力してください。

## 開発・パッケージ作成

Node.js >= 22.12（この環境では24.19.0）:

```sh
npm install
npm run dev
```

`npm run dev`は開発用のViteです。通常配布物は静的ファイルで、起動時にこのサーバーへ接続しません。

```sh
npm ci
npm run test
npm run build
npm run pack
```

`npm run pack`はビルド後に公式CLIの`evenhub pack app.json dist --sdk-ver 0.0.16 -o releases/transit-hud-0.3.0.ehpk`を実行します。生成物をHubへアップロードしてください。CLIによるSDK互換版のnpm取得が失敗する環境でも、manifestは実際のSDKが要求する`min_app_version: 2.2.10`を指定しています。警告が出た場合は最新公式SDK metadataを再確認してください。

スマホ画面の自動テスト:

```sh
npx playwright install chromium
npm run test:browser
# 既にChromiumがあるクラウド環境:
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

本番静的ファイルでの同じテストには`PLAYWRIGHT_BASE_URL`を使えます。実機リリース確認は[DEVICE-TEST.md](docs/DEVICE-TEST.md)。

```text
src/
  main.ts                  スマホ/Bridge/更新処理の統合
  config.ts                公式GTFS一覧・許可済み公開配信元
  even/                    公式Bridge、G2 renderer、入力、Contextual Menu
  transit/                 純粋な時刻表・乗車可否・直通/最大2回乗換検索
    odpt/                  公式列車時刻表JSON parser/Worker、認証取得
    gtfs/                  CSV/ZIP parser、Worker、HTTPS loader、公式Realtime schema
  state/                   SDK/IndexedDB保存、自動ルート選択
  ui/                      日本語設定画面、スマホstyles
  utils/                   ホストtimezoneに依存しないJST処理
tests/                     ロジック・SDK制約・保存障害・ブラウザ操作
docs/                      調査、Privacy Policy、実機確認
```

## データとオンライン更新

初期時刻表は東京都交通局・公共交通オープンデータ協議会の鉄道GTFS 20260921版、CC BY 4.0です。[出典とライセンス](public/feeds/README.md)。架空サンプルは実際の乗車には使えません。

ネットワーク権限とCSPは `api-public.odpt.org`、`api.odpt.org`、`api-challenge.odpt.org`、`dataodpt.blob.core.windows.net` に限定しています。ODPTの最新版URL・dateだけの日付指定URLを取得し、署名付きの転送先は永続保存しません。自由入力の認証入りURLは受け付けません。確認済み認証配信の鍵は専用設定から入力し、取得時だけ公式配信先へ送信します。鍵はメモリだけに保持し、保存・再表示しません。終了後は再入力が必要ですが、時刻表は端末に残ります。指定外の配信元はファイル取込で使用してください。時刻表と設定は端末内に保存し、利用者の情報を外部へアップロードしません。位置情報・マイク・解析通信はありません。[プライバシー](docs/PRIVACY.md)。

通信障害では保存済みデータを使い、有効期限切れの配布元の列車は案内しません。ダイヤの公表前や日付固定URLでは最新ダイヤを保証できません。駅・路線IDが改正で変わった場合は保存ルートを編集してください。時刻補正は残せますが、便・停車順が変わった補正は解除されます。認証取得した公式便とODPT JSONの便は時刻補正できません。

GTFS ZIP12MB/展開60MB/1配布元20,000便を上限とします。頻度ベースや列車・路線限定のtransfersなど、GTFSの全機能に対応したものではありません。

## 注意

日本語フォントとコンテナ内の文字収まり、Even Hub WebViewでの永続性、ファイル選択、Worker、実機の再接続は確認が必要です。乗車モードは時刻ベースで、実際の乗車/到着検知ではありません。リアルタイムがない時の運休は検知できません。駅・事業者の最新案内を優先してください。

本プロジェクトには公式テンプレート由来の入力処理・基本コンテナ構成と公式GTFS-Realtime schemaを含みます。ライセンスは`docs/EVEN-TEMPLATE-LICENSE`と`docs/GTFS-LICENSE`を参照してください。
